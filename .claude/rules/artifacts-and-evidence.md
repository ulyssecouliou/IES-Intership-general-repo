# Artifact and Evidence Rules

- Treat these files as generated, licensed, official, customer-owned or reviewer-owned unless proven otherwise.
- Do not edit, rename, delete, normalize or regenerate them unless the user explicitly requests that exact operation.
- Never fabricate official SIA 4010 evidence, reviewer approval, software-register status or candidate PASS results.
- Preserve original filenames, checksums and provenance in evidence workflows.
- Prefer creating a new timestamped artifact to overwriting an existing evidence artifact.
