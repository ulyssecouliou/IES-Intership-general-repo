# `references`

Local reference material used during development and compliance traceability.

## Folders

- `standards/`: local SIA PDF reference copies.
- `iesve/`: IESVE API notes and reference PDFs.
- `iesve/class_structure/`: extracted IESVE class-structure reference files used
  while improving extraction coverage.

These files support development and review. They are not generated by the
checker.
