**Subject:** SIA 2028 climate datasets and SIA 2024 usage data — two practical
questions

Dear Mr Yang,

Thank you again for your earlier answers. Since then we have implemented the
SIA 4010 test evaluation in IES Virtual Environment and started applying it to
a real client project. Two data questions now block us, and one is decisive.

---

**1. SIA 2028 hourly data including the solar radiation components.**

This is the one that blocks everything else.

The SIA 4010 test specifications require *« SIA 2028 DRY normal, Zürich
Kloten »*. We have been able to reconstruct the **hourly dry-bulb temperature**
for Kloten from an official SIA workbook, and it is consistent
(8 760 values, min −13.02 °C, max 34.10 °C, annual mean 9.47 °C).

What we have **not** been able to obtain is the **solar radiation** for the
same station — global, direct and diffuse, or the plane-of-array values.
Without it we cannot run any of the seven tests under the specified climate,
and consequently **none of the eight validation classes can be completed**.

Could you tell us:

- which official product carries the hourly SIA 2028 *DRY normal* data
  **including solar radiation** (the `Original-SIA-Datei` `.PRN` files appear
  to, but we have not been able to establish how to obtain them);
- whether IES, as a software vendor implementing SIA 4010, can obtain that
  dataset for validation purposes, and under what terms.

We are of course prepared to purchase it. Our difficulty so far has been
identifying the correct product rather than the cost.

---

**2. Which climate basis a SIA 380/2 compliance calculation must use.**

We are now preparing a compliance assessment for a real Swiss building, and we
want to get this right rather than assume.

- Must the calculation use an **SIA 2028 station dataset**, or are other
  recognised sources (Meteonorm, IWEC, TMY) acceptable for SIA 380/2?
- If SIA 2028 is required, is a **converted file** (e.g. EnergyPlus `.epw`)
  acceptable, provided the conversion is documented? Is there a reference
  conversion, or a checksum, against which a converted file can be verified?
- How should the **station be selected** relative to the building, and is there
  a stated tolerance on the **altitude difference** between station and site?

We ask because our software will otherwise happily produce results from any
weather file. We would rather refuse a file than report a defensible-looking
number computed on the wrong climate.

---

**3. SIA 2024 usage data — machine-readable form.**

We have located the SIA 2024:2021 usage data sheets available free of charge,
and thank you for the pointer. Our question is narrower: does the SIA publish
these standard usage profiles in a **machine-readable form** (CSV, XML or
similar), or is transcription from the PDF sheets the expected route?

Transcribing them by hand is possible but introduces a class of error we would
rather avoid, given that these values feed every test from 2 to 6.

---

Thank you in advance. Question 1 is the one that currently prevents us from
completing any validation class, so any pointer there would be especially
welcome.

Kind regards,

Ulysse Couliou
IES — Integrated Environmental Solutions
