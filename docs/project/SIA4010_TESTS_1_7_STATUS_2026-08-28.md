## Actions that cannot be completed safely outside IESVE or without review

- A Python process outside the active VE session cannot prove that an Apache
  Systems topology, template inheritance, CDB state or result binding behaves
  correctly in IESVE 2025.
- Source receipt is not cell validation. The workbook must be inspected and
  rendered with an approved spreadsheet workflow before its values become
  normative bindings.
- Missing SIA tolerances must not be invented. Candidate-specific fan
  approximations require documented engineering validation and sensitivity,
  not an invented official threshold.
- The software provides technical evidence and comparisons; it does not issue
  official SIA accreditation or certification.
