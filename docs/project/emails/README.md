# Project Email Archive

This folder contains 60 Outlook `.msg` files exported from the project
email exchanges. They document the communication with the SIA commission
and internal stakeholders throughout the SIA 4010 / SIA 380/2 validation
project.

## Contents

The emails cover the following threads:

| Thread | Description |
|--------|-------------|
| `Validation SIA 4010 et 380_2` | Main thread with the SIA commission (FR/DE) |
| `SIA 380_2 and SIA 4010` | English-language thread on the same topic |
| `SIA 4010 validation of IESVE — access to a few specific tables` | Request for SIA reference data tables |
| `SIA Test Cases 1-7 Request Form` | Formal test-case request exchanges |
| `Clarification request — SIA 4010 Test 1E external shading control` | Specific norm clarification |
| `Clarification required for SIA 4010 Test 2A — SIA 2024 profile calendar` | Specific norm clarification |
| `Many thanks and consolidated remaining questions` | Summary of open questions |
| `Contract`, `First day at IES`, `Norme suisse` | Project setup and onboarding |

Prefix conventions: `RE_` = reply, `AW_` = Antwort (German reply),
`FW_`/`TR_`/`WG_` = forwarded.

## How to open

These are Outlook `.msg` files. Open them with:
- Microsoft Outlook (double-click)
- Any `.msg` viewer (e.g. Free Opener, MSG Viewer for web)

## Publication and handling notice

These files may contain personal information and internal correspondence.
Their inclusion in the project repository, including their future public
availability if the repository is made public, was explicitly authorized by the
project owner on 27 August 2026 because they are required for continuity,
normative traceability and follow-up with the SIA commission. At the time of the
final handover audit, the repository itself still returned HTTP 404 to anonymous
requests and was therefore private or access-restricted.

Future maintainers must treat the messages as project evidence: do not alter
the originals, avoid copying them outside the project unnecessarily, and ask
the IES project owner to review continued public availability if the repository
ownership, access policy or applicable privacy requirements change.
