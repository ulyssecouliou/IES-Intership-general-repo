## 1. Objet et limite juridique

Le dépôt contient deux produits liés mais distincts :

1. une évaluation technique d'un modèle client IESVE selon SIA 380/2:2022 ;
2. une chaîne de préparation, qualification et collecte de preuves pour les
   tests de validation logicielle SIA 4010.

Le logiciel ne délivre pas de certificat officiel SIA, ne remplace pas le
relecteur compétent et ne peut pas convertir une preuve absente en conformité.
Les verdicts restent volontairement *fail-closed*.

## 4. État des tests de validation SIA 4010

### Test 1

- six cas ISO de référence (`600`, `640`, `600FF`, `900`, `940`, `900FF`)
  simulés et enregistrés ;
- quatre livrables diagnostiques annuels (`1A` à `1D`) enregistrés ;
- `1E` préparé, contrôles d'ombrage `150/150 W/m²` confirmés par le
  professeur Gerhard Zweifel et qualifiés dans VE ;
- Test 1 global **non terminé** car `1E` échoue encore la comparaison officielle.

Blocage 1E principal : VE 2025 renvoie les réflectances de protection externe
à environ `0.100`, tandis que les valeurs recherchées sont :

```text
external_shade_solar_reflectance   = 0.490
external_shade_visible_reflectance = 0.496
```

Les setters Python ne sont pas exposés (`unrecognised option`) et les champs
n'ont pas été identifiés dans APcdb. Ne pas remplacer ce blocage par une
hypothèse silencieuse. Autres réserves : équivalence optique APS, rayonnement
incident sur le plan extérieur non exposé dans l'APS essayé, coefficients de
surface radiatifs non disponibles dans les séries APS et échec numérique de la
bande officielle 1E.

### Test 2A

- setter du contrôle d'ombrage : `PASS` ;
- sous-ensemble optique inscriptible 2E1 : `PASS` ;
- non terminé : graphes de profils natifs, réflectances non inscriptibles,

### Test 3

### Tests 4, 5, 6 et 7

## 5. Validation logicielle reproductible

Depuis la racine du dépôt :

```powershell
python -m pytest -q
python -m black --check --line-length 90 core engine schemas swiss_sia ui scripts tests ve_adapter
python -m flake8 swiss_sia ui scripts core schemas engine ve_adapter tests --jobs 1 --config .flake8
python -m mypy --strict --show-error-codes core schemas
python -m mypy --strict --show-error-codes --exclude '^$' swiss_sia/assessment_governance.py swiss_sia/client_report_context.py swiss_sia/project_evidence_translations.py swiss_sia/value_integrity.py
```

Sous un sandbox Windows qui interdit l'accès aux répertoires temporaires, la
suite peut produire de nombreux faux `PermissionError`. La référence de
livraison doit être exécutée avec un `%TEMP%` pleinement accessible. Les tests
exigeant le runtime natif IESVE doivent en plus être lancés depuis VE 2025.
