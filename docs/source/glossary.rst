Glossary
========

.. glossary::

   Automated compliance indicator
      Weighted score based on currently implemented or partial SIA 380/2 checks.
      It is not a certificate.

   Health score
      Model-quality indicator based on completeness, consistency, and critical
      extraction issues.

   NOT_CHECKABLE
      The checker cannot decide without external evidence, official files, or a
      confirmed VE mapping.

   NOT_IMPLEMENTED
      The criterion is known and source-traced, but automation has not been
      implemented yet.

   PARTIAL_CHECK
      Useful evidence is available, but not enough for a complete compliance
      verdict.

   SIA 380/2
      Swiss standard used here for thermal energy and building-system readiness
      checks according to the implemented scope.

   SIA 4010
      Swiss standard used here for method/software validation readiness through
      official tests, evidence files, and validation classes.

   Validation class
      SIA 4010 class defining which official validation tests must be passed.

   VE Run-button workflow
      End-user workflow where the script is executed directly from the IESVE
      Scripts window without PowerShell.
