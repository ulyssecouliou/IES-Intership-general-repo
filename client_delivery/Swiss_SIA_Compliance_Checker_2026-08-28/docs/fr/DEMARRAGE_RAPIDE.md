# Démarrage rapide

1. Conserver tout le dossier de livraison ensemble.
2. Ouvrir et enregistrer le modèle à analyser dans IESVE 2025.
3. Vérifier que le dernier APS annuel correspond à l'état actuel du modèle.
4. Dans la fenêtre Scripts de VE, lancer `Run_VE_Swiss_Compliance.py`.
5. Renseigner le client, le projet, l'auteur, la référence et les déclarations
   propres au bâtiment.
6. Utiliser **Project Evidence** pour compléter et revoir les sept familles de
   preuves.
7. Capturer l'image du Model Viewer.
8. Cliquer sur **Generate Excel + PDF**.
9. Lire les réserves et demandes de données avant de transmettre le rapport.

Les rapports sont enregistrés dans :

```text
<projet VE>/SIA Compliance Reports/
```

Les preuves propres au modèle sont enregistrées dans :

```text
<projet VE>/sia4010_evidence/
```

Le nom historique de ce dossier ne transforme pas l'évaluation du bâtiment en
validation SIA 4010. Le rapport client reste une évaluation d'ingénierie
SIA 380/2, et non un certificat officiel.
